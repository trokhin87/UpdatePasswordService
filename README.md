# PasswordRecoveryService

## 1. Название и назначение сервиса
PasswordRecoveryService — микросервис, который управляет процессом восстановления пароля для пользователей. Он принимает запросы от других сервисов и выполняет сброс пароля с использованием токенов.

## 2. Архитектура и зависимости
### Технологии и фреймворки:
- ASP.NET Core
- Swashbuckle (Swagger) для документации API
- Serilog для логирования
- JWT для работы с токенами
- HttpClient для взаимодействия с другими микросервисами

### Взаимодействие с другими микросервисами:
- Взаимодействует с ProxyMicroservice для получения данных пользователей, таких как ID и login.
- Использует Kafka как брокер сообщений для асинхронных операций (если настроено).

### Внешние сервисы:
- SMTP-сервер для отправки email с токенами для восстановления пароля.
- Kafka (если используется).
