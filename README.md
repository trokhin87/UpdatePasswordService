# PasswordRecoveryService

## 1. Название и назначение сервиса
PasswordRecoveryService — микросервис, который управляет процессом восстановления пароля для пользователей. Он принимает запросы от других сервисов и выполняет сброс пароля с использованием токенов.

## 2. Архитектура и зависимости
### Технологии и фреймворки:
- ASP.NET Core
- Swashbuckle (Swagger) для документации API
- Serilog для логирования
- JWT для работы с токенами
- HttpClient для взаимодействия с другими микросервисами

### Взаимодействие с другими микросервисами:
- Взаимодействует с ProxyMicroservice для получения данных пользователей, таких как ID и login.
- Использует Kafka как брокер сообщений для асинхронных операций (если настроено).

### Внешние сервисы:
- SMTP-сервер для отправки email с токенами для восстановления пароля.
- Kafka (если используется).

## 3. Способы запуска сервиса

### Запуск через Docker:
```sh
docker-compose up --build
```
### Альтернативный запуск:
```
dotnet run
```
### Переменные окружения (.env):
| Переменная       | Описание |
|------------------|----------|
| SMTP_HOST       | Адрес SMTP-сервера |
| SMTP_PORT       | Порт SMTP-сервера |
| SMTP_USER       | Логин для SMTP |
| SMTP_PASSWORD   | Пароль для SMTP |
|PASSWORD_RESET_TOKEN_SECRET	| Секретный ключ для генерации токенов|

## 4. Способы запуска сервиса
### Документация API доступна в Swagger:
```
http://localhost:5000/swagger/index.html
```
### Основные эндпоинты:
- POST /api/passwordrecovery/request-reset-password — инициирует запрос на сброс пароля, отправляя ссылку на указанный email.

 - 200 — ссылка для сброса пароля отправлена.

 - 400 — ошибка: пользователь не существует или отправка письма не удалась.

- POST /api/passwordrecovery/reset-password — сбрасывает пароль с использованием токена.

 - 200 — пароль успешно обновлен.

 - 400 — ошибка: неверный токен или не удалось обновить пароль.
